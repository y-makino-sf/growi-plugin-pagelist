
# GROWI「配下ページ一覧＆ポータル表示」プラグイン (growi-plugin-pagelist) 仕様書

## 1. 記法とオプション仕様

Markdown本文内で `$pagelist(...)` を記述することで、用途に応じた一覧を描画する。

| オプション | 指定可能な値 | デフォルト値 | 説明 |
| :--- | :--- | :--- | :--- |
| **対象パス**（第1引数 / `path`） | パス文字列（例: `/TechKnowhow`） | 現在のページパス | 探索起点となる親ページパス。起点ページ自身は一覧から自動除外される。 |
| **`limit`** (別名: **`num`**) | 数値（例: `5`, `10`） | `10` | 1ページあたりの表示件数。 |
| **`recursive`** | `true` / `false` | `true` | `true`: サブフォルダ以下全階層を再帰探索。<br>`false`: 直下の1階層のみ探索。 |
| **`sort`** | `updatedAt` (更新日時順)<br>`createdAt` (作成日時順)<br>`popular` (人気総合スコア順)<br>`views` (閲覧者数順)<br>`likes` (いいね数順) | `updatedAt` | 並び順の指定。`popular` は `(いいね数 × 2) + 閲覧者数` で算出する。`popular` / `views` / `likes` 指定時はランキング王冠バッジと閲覧数・いいね数を強調表示する。 |
| **`tag`** | タグ名（例: `pickup`, `必読`） | `""` (指定なし) | 指定時は `GET /_api/search?q=tag:<tag>` を呼び出し、該当タグが付いたページを抽出する（対象パスも指定されている場合はそのパス配下で絞り込む）。 |
| **`view`** | `list` (リスト表示)<br>`card` (カードグリッド表示) | `list` | `list`: コンパクトな1列リスト。<br>`card`: Bootstrapカードを用いた2列グリッド表示（おすすめ枠・人気枠向け）。 |
| **`newdays`** | 数値（例: `3`, `7`, `0`） | `3` | 指定日数以内に更新されたページに `NEW` バッジを表示する（`0` で非表示）。 |

## 2. API呼び出しとデータ整形の内部設計
1. **通常取得（`tag` 未指定時）**:
   - `GET /_api/v3/pages/list?path=...&limit=...&page=...` を呼び出す。
   - ただし、`sort` が `popular` / `views` / `likes` の場合や `recursive=false` の場合は、クライアント側で全件ソート・階層フィルタを行うため `limit=100, page=1` で母集団を取得し、クライアント側でソートおよびページネーション（スライス）を行う。
2. **タグ検索取得（`tag` 指定時）**:
   - `GET /_api/search?q=tag:<tag>` を呼び出す。レスポンスの `data` 配列（または `pages` 配列）からページ情報を抽出し、指定パス配下のフィルタおよびソート・ページングを適用する。
